# Student Grade Analyzer

## Description

Student Grade Analyzer is a Python-based application that analyzes student academic performance.

The program calculates student averages, assigns performance categories, identifies the highest-performing student, separates passing and failing students, and generates a performance report.

## Features

- Calculate average grades for multiple subjects
- Categorize student performance:
  - Excellent
  - Good
  - Average
  - Needs Improvement
- Identify the highest-performing student
- Separate passing and failing students
- Generate a text-based performance report

## Technologies Used

- Python 3
- Dictionary data structures
- Functions
- File handling
