# Student Data Cleaning and Analysis

## Description

This project uses Python and Pandas to clean and analyze student performance data stored in a CSV file.

## Features

- Reads student data from a CSV file
- Detects missing values
- Fills missing English scores
- Calculates student average scores
- Assigns performance categories
- Identifies students with low attendance
- Finds the top-performing student
- Calculates average attendance

## Technologies Used

- Python
- Pandas
- CSV

## What I Learned

This project helped me practice working with real-world style tabular data, handling missing values, filtering data, calculating statistics, and creating new columns using Pandas.
