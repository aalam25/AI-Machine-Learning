# Precision and Recall

## Precision

Precision answers:

> Of the students predicted as Pass, how many actually passed?

The formula is:

```text
Precision = TP / (TP + FP)
```

Where:

- `TP` = True Positives
- `FP` = False Positives

A higher precision means fewer negative cases are incorrectly predicted as positive.

---

## Recall

Recall answers:

> Of all students who actually passed, how many did the model identify?

The formula is:

```text
Recall = TP / (TP + FN)
```

Where:

- `TP` = True Positives
- `FN` = False Negatives

A higher recall means the model identifies more of the actual positive cases.

---

# Precision-Recall Curve

A Precision-Recall Curve shows the relationship between precision and recall at different classification thresholds.

The curve was calculated using:

```python
precision, recall, thresholds = precision_recall_curve(
    y_test,
    y_probability
)
```

The actual results were:

```text
Precision:
[0.8        0.88888889 1.         1.         1.        ]

Recall:
[1.    1.    1.    0.875 0.   ]

Thresholds:
[0.   0.02 0.29 1.  ]
```

The threshold changes the point at which the model classifies a student as belonging to the positive class.

For example, a lower threshold can identify more positive cases, which can increase recall. A higher threshold can make the model more selective, which can increase precision.

---

# Average Precision

Average Precision (AP) summarizes the performance shown by the Precision-Recall Curve into a single score.

It was calculated using:

```python
average_precision_score(
    y_test,
    y_probability
)
```

The actual result was:

```text
Average Precision Score:
1.0000
```

An Average Precision score of `1.0000` indicates perfect precision-recall ranking on this particular test set.

However, the test set contains only 10 samples, so this result should be interpreted carefully.

It does not prove that the model will achieve an AP of `1.0000` on new or larger datasets.

# Average Precision vs Accuracy

Accuracy and Average Precision measure different aspects of a classification model.

### Accuracy

Accuracy measures the proportion of all predictions that were correct.

```text
Accuracy = Correct Predictions / Total Predictions
```

### Average Precision

Average Precision summarizes the relationship between precision and recall across classification thresholds.

Therefore, Average Precision can provide useful information that a single accuracy value does not provide.

---

# Precision-Recall vs ROC Curve

This project follows the ROC Curve and AUC project from Day 24.

Both are useful for classification evaluation, but they focus on different relationships.

### ROC Curve

ROC evaluates:

```text
True Positive Rate
vs.
False Positive Rate
```

### Precision-Recall Curve

Precision-Recall evaluates:

```text
Precision
vs.
Recall
```

The Precision-Recall Curve can be particularly useful when the positive class is important or when class distributions are imbalanced.
