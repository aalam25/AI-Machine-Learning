# NumPy Practice

## Description

This project demonstrates basic NumPy operations using student score data.

## Features

- Create NumPy arrays
- Calculate average score
- Find highest and lowest scores
- Count total students
- Assign letter grades
- Display student performance

## Technologies

- Python 3
- NumPy

## Future Improvements

- Read scores from a CSV file
- Visualize scores using Matplotlib
- Analyze larger datasets
