# Student Statistics Analyzer

## Description

This project uses Python and NumPy to analyze student scores and calculate basic statistical measurements. The project is designed to practice statistics concepts that are commonly used in data science and machine learning.

## Features

- Calculates the mean score
- Calculates the median score
- Finds the minimum score
- Finds the maximum score
- Calculates variance
- Calculates standard deviation
- Calculates average scores for different subjects
- Identifies the subject with the highest average
- Calculates the correlation between study hours and scores
- Interprets the correlation between two variables

## Dataset

The project uses sample student scores for three subjects:

- Math
- Science
- English

It also uses sample study-hour and score data to demonstrate correlation.

## Technologies Used

- Python
- NumPy

## Example Analysis

The program calculates statistics for each subject and identifies the subject with the highest average score.

It also analyzes the relationship between study hours and student scores using correlation.
