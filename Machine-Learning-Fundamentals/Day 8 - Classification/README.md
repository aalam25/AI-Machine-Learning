# Student Pass/Fail Prediction Using Logistic Regression

## Description

This project is my second machine learning project and my first classification project using Python and Scikit-learn.

The goal of this project is to train a Logistic Regression model to predict whether a student will pass or fail based on their exam score.

The project demonstrates the basic workflow of a classification problem, including preparing data, splitting the dataset into training and testing sets, training a classification model, making predictions, calculating prediction probabilities, and evaluating the model.

## Machine Learning Approach

This project uses **Logistic Regression** for binary classification.

The model predicts one of two possible classes:

```text
0 → Fail
1 → Pass
```

### Feature and Target

- **Feature:** Exam Score
- **Target:** Pass/Fail

### Machine Learning Workflow

```text
Dataset
   ↓
Feature and Target
   ↓
Train/Test Split
   ↓
Logistic Regression
   ↓
Model Training
   ↓
Predictions
   ↓
Prediction Probabilities
   ↓
Model Evaluation
   ↓
New Student Prediction
```

## Features

The program:

- Creates a dataset using NumPy
- Separates the feature and target variables
- Splits the data into training and testing sets
- Creates a Logistic Regression model
- Trains the model
- Makes predictions on test data
- Calculates prediction probabilities
- Calculates model accuracy
- Generates a confusion matrix
- Predicts whether a new student will pass or fail
- Calculates the probability that a new student will pass
- Uses a reusable function to make predictions for different scores

## Model Evaluation

The project uses two main evaluation methods.

### Accuracy

Accuracy measures the percentage of predictions that the model gets correct.

```text
Accuracy = Correct Predictions / Total Predictions
```

A higher accuracy generally indicates that the model is making more correct predictions.

### Confusion Matrix

The confusion matrix shows how many predictions were classified correctly and incorrectly for each class.

It helps identify whether the model is making mistakes when predicting:

- Fail
- Pass

## Prediction Probabilities

The project uses:

```python
model.predict_proba()
```

to calculate the probability of each class.

For example:

```text
Fail Probability → 0.20
Pass Probability → 0.80
```

This means the model estimates an 80% probability that the student will pass.

## Example Prediction

The model is tested with a student who has an exam score of 72.

The program displays:

```text
Score: 72
Prediction: Pass/Fail
Pass Probability: [model prediction]
```

The actual prediction and probability are generated by the trained model when the program runs.

The program also tests predictions for students with scores of:

- 45
- 65
- 85

## Reusable Prediction Function

A reusable function called `predict_result()` was created to make predictions for different exam scores.

Example:

```python
predict_result(45)
predict_result(65)
predict_result(85)
```

This allows the model to be tested with different student scores without repeating the prediction code.
