# Student Performance Visualizer

## Description

A beginner Python data analysis project that uses NumPy and Matplotlib to analyze and visualize student performance.

## Features

- Calculates student average scores
- Displays average scores
- Creates a student performance bar chart
- Identifies the top-performing student
- Identifies students needing improvement

## Technologies Used

- Python
- NumPy
- Matplotlib
