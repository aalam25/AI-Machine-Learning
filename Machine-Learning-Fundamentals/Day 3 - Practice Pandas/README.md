# Student Performance Analyzer

## Description

A Python data analysis project using Pandas to analyze student academic performance.

## Features

- Create and analyze student datasets
- Calculate average scores
- Identify top-performing students
- Filter students based on performance
- Detect students needing improvement

## Technologies Used

- Python
- Pandas

## Future Improvements

- Read data from CSV files
- Add visualization using Matplotlib
- Build a machine learning model to predict performance
