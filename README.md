# AI & Machine Learning 90-Day Learning Journey

Welcome to my **AI & Machine Learning** learning repository.

This repository documents my 90-day journey of learning, practicing, and building projects in **Artificial Intelligence and Machine Learning**. My goal is to develop practical skills, build a strong portfolio, and prepare myself for entry-level opportunities in AI/ML.

Rather than focusing only on theory, I am learning by **building projects, experimenting with data, evaluating models, solving problems, and documenting what I learn**.

## Main Goal

My goal is to build a strong foundation in AI and Machine Learning and gradually progress toward more advanced areas such as:

- Machine Learning
- Advanced Machine Learning
- Deep Learning
- Natural Language Processing (NLP)
- Large Language Models (LLMs)
- Generative AI
- Computer Vision
- Practical AI applications
- End-to-end AI/ML projects

By the end of this journey, I want to have both the **technical foundation and practical project experience** needed to pursue entry-level AI/ML opportunities.

## 90-Day Roadmap

The journey is organized into learning phases so that each phase builds on the previous one.

| Days | Learning Phase | Main Focus |
|---|---|---|
| 1–25 | Machine Learning Fundamentals | Python, NumPy, pandas, visualization, statistics, data preparation, regression, classification, and model evaluation |
| 26–40 | Advanced Machine Learning | Feature engineering, advanced models, model optimization, pipelines, ensemble methods, and reliable evaluation |
| 41–55 | Deep Learning | Neural networks, training, optimization, TensorFlow/PyTorch, and deep learning projects |
| 56–65 | Natural Language Processing | Text preprocessing, text classification, embeddings, sentiment analysis, and NLP applications |
| 66–75 | LLMs & Generative AI | Transformers, LLM concepts, prompting, APIs, RAG, embeddings, and generative AI applications |
| 76–82 | Computer Vision | Image processing, image classification, CNNs, transfer learning, and computer vision applications |
| 83–90 | Practical AI Projects | End-to-end AI projects, deployment, documentation, portfolio development, and real-world applications |

This roadmap is designed as a progression rather than a collection of unrelated projects.

## Learning Approach

My approach to this 90-day journey is based on **learning by doing**.

For each project, I aim to:

1. Learn the concept.
2. Understand why it is used.
3. Write the code myself.
4. Run and test the code.
5. Analyze the results.
6. Create visualizations when appropriate.
7. Document what I learned.
8. Save the project in GitHub.
9. Reflect on what could be improved.

This approach helps me turn theoretical knowledge into practical experience.
